# Rds-data-optimization
Optimización y limpieza de bases de datos

Plan de Optimización Administrativa
Objetivo General: Centralizar la información, optimizar procesos, eliminar duplicidades y asegurar que los datos financieros y de inventario sean confiables para la toma de decisiones.
1. Limpieza de Bases de Datos
Depuración de Tablas: Limpieza de las bases de artículos, proveedores y clientes en Memory. Eliminación de duplicados y corrección de errores de carga.
Estandarización de Criterios: Creación de un "Maestro de Artículos" con códigos únicos por artículo independientes al proveedor de compra para que la información sea uniforme en todas las áreas.
Listas de Precios: En base al Maestro de Artículos, crear lista de precios de ventas únicas y actualizables por proveedor.
Plantilla de Presupuestos: Unificar una plantilla de presupuestos con la base al Maestro de Artículos y lista de precios actualizadas
2. Control de Inventarios y Operaciones
Sincronización Stock-Ventas: Una vez limpias las bases, implementar un sistema de control de existencias real.
Gestión de Flota : Registro de kilometraje, mantenimientos preventivos y vencimiento de Documentación
Gestión de Personal : Control de horarios y facturación a Clientes de forma digital.
Gestión de Trabajos y Pedidos pendientes : Crear un registro que permita  seguimiento y facturación y proyección
3. Integración Financiera y Flujo de Fondos
Unificación de Cajas y Bancos: Migrar los Excel independientes a un modelo integrado que permita ver el Flujo de Fondos proyectado.
Control de Cuentas Corrientes: Seguimiento de saldos de clientes y deudas con proveedores para optimizar la liquidez
4. Tablero de Resultados (Dashboard)
Indicadores Clave: Creación de un resumen ejecutivo mensual que muestre la rentabilidad real, márgenes por lista de precios y estado de resultados.
